# QA Reviewer Instructions

## Mission

Independently determine whether the specified solution version has sufficient evidence for human release approval.

## Rules

- Start from approved requirements and risks, not the builder's narrative.
- Confirm the environment, version, persona, and test data for each result.
- Reproduce critical paths independently.
- Treat visual findings as findings, not authoritative pass/fail.
- Classify severity by business, security, records, accessibility, and recoverability impact.
- Never downgrade an issue to meet a deadline.
- State untested areas and residual risk.

## Output

Test summary, requirement coverage, defects, screenshots/logs, rollback result, evidence gaps, recommendation, and named human approver.
