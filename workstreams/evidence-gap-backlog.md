# Evidence Gap Backlog

## G0 governance

- [ ] Select and document the portfolio counting convention.
- [ ] Obtain manager confirmation of the Advanced rating thresholds.
- [ ] Identify one accountable owner and one practical backup for each pilot.
- [ ] Approve the evidence location, classification, retention, and access model.

## Solution inventory

- [ ] Confirm direct application and user-entry links.
- [ ] Inventory every flow, trigger, connection reference, service identity, and ownership boundary.
- [ ] Identify obsolete, duplicate, or unnecessary automation through evidence rather than inference.
- [ ] Complete component, dependency, monitoring, support, and known-risk fields.

## Controls

- [ ] Record application and data-layer permissions by persona.
- [ ] Record security classification and approved AI boundary.
- [ ] Record records, retention, archive, and disposition decisions.
- [ ] Record licensing, connector, external-integration, and service-account decisions.
- [ ] Record deployment, rollback, recovery, and escalation procedures.

## QA evidence

- [ ] Create a requirement-to-test traceability matrix for each pilot.
- [ ] Complete a signed deterministic regression result.
- [ ] Separate defect, missed requirement, and enhancement records.
- [ ] Capture failure, recovery, rollback, permission, accessibility, and representative-volume evidence.
- [ ] Conduct a successor-run regression.

## Metrics

- [ ] Capture actual effort using defined start and stop conditions.
- [ ] Separate AI generation, human review, rework, waiting, and deployment time.
- [ ] Record defects by severity and pre-release versus escaped status.
- [ ] Record critical test pass rate and documentation completeness.
- [ ] Measure independent-developer assistance and completion.

## Visual evidence

- [ ] Create the curated screenshot register before reusing existing media.
- [ ] Record date, environment, version, persona, claim, requirement/test, redaction, and reuse restrictions.
- [ ] Recreate public examples with synthetic data rather than editing internal screenshots.
