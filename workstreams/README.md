# Workstreams

This folder is reserved for branch-owned, workstream-specific artifacts that are intentionally isolated from the shared standards library.

## Current workstreams

- `powerapps/` for Power Apps design, UX, and governance artifacts
- `powerautomate/` for flow architecture, test cases, and recovery work
- `sharepoint/` for SharePoint data and information architecture artifacts
- `qa/` for validation, evidence, screenshot, and release readiness work
- `portfolio/` for measurement, portfolio, and blog evidence

Each workstream should contain:

- a `README.md` describing the scope
- a backlog or checklist
- versioned output and handoff notes
- evidence references required for review

Keep these areas isolated so parallel agents can work without stepping on shared files.
