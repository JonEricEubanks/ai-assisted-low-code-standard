## Metrics tasks

- [ ] For each pilot, define the comparable unit of work, baseline and outcome periods, activity start/stop conditions, sample size, data source, and exclusions before collecting results.
- [ ] Record actual minutes separately for AI generation (`AI Assisted Minutes`), human review, rework, waiting, and deployment; distinguish active effort from elapsed waiting time.
- [ ] Record defects by severity and pre-release versus escaped status; define critical-test pass rate as passed/planned (N/A when none are planned), document the completeness denominator, and define independent completion and assistance.
- [ ] Report sample size, median, range, exclusions, and confidence/uncertainty for comparable baseline/outcome observations; do not combine different units or present association as causation.
- [ ] Classify every benefit as **realized** (supported by actual, comparable observations and cited evidence), **projected** (estimate with assumptions and method stated), or **unmeasured** (no reliable result yet). Never count projections or planning estimates as realized benefits; unknown is not zero.
- [ ] Build an Advanced-rating evidence dashboard specification that shows the benefit classification, metric definitions, source, comparison, and limitations for each claim.
