Setup complete

You are ready when all six checks are true.

  • VS Code has this repository open as the active workspace.
  • Git works from the terminal.
  • Both recommended extensions are enabled.
  • GitHub Copilot Chat shows the MGP Delivery agent.
  • az --version succeeds.
  • The approved MCP connection can list and read an authorized CSM folder.

The readiness script verifies local tools and repository files. Tenant authentication still requires the manual folder-read check above.

Human control

If SharePoint access is missing, documents are inaccessible, or Tier 1 questions remain unanswered, the agent must stop and report the blocker instead of pretending the intake is complete.
