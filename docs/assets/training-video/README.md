# Training Video Storyboard Assets

These screenshots support the 90-second MGP Developer Delivery Guide orientation video.

## Sequence

### 1. Establish the delivery route

![Homepage hero](./01-homepage-hero.png)

**Narration:** The MGP Developer Delivery Guide gives every solution one clear path from request to handoff.

### 2. Choose the platform playbook

![Platform playbooks](./02-homepage-playbooks.png)

**Narration:** Open the playbook for your platform. You do not need to read the entire repository.

### 3. Jump directly to a resource

![Resource index](./03-homepage-resources.png)

**Narration:** Experienced developers can go directly to the standard, procedure, governance model, or workflow they need.

### 4. Choose a quick-start route

![Task routes](./04-training-task-flow.png)

**Narration:** Developers can review a CSM handoff, build with a platform quick path, or validate and release.

### 5. Follow the release checklist

![Release checklist](./05-training-release-checklist.png)

**Narration:** Before release, confirm the test target, run deterministic checks, test the live requirement, classify evidence, pass the release gate, and transfer ownership.

### 6. Use the focused platform standard

![Platform standards](./06-training-standards.png)

**Narration:** Choose a quick path for Azure guardrails, Power Apps, Power Automate, SharePoint, or an integrated solution, and capture evidence as you work.
