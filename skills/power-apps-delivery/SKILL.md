# Power Apps Delivery

## Procedure

1. Confirm approved requirements, personas, data contract, and screen specification.
2. Inventory current controls and data sources before editing an existing app.
3. Produce a bounded edit plan and assess it before execution.
4. Use Canvas authoring tools for supported changes; do not bypass approval for production changes.
5. Compile/sync the app and resolve errors.
6. Run App Checker and accessibility checks.
7. Test critical journeys, permission boundaries, error states, responsiveness, delegation, and representative volume.
8. Capture screenshots and structured evidence.
9. Update architecture, release notes, test results, and handoff documentation.

## Required outputs

App version, edit plan, validation results, screenshots, defect disposition, rollback reference, and reviewer approval.
