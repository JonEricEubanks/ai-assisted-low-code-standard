# Architecture and Impact

## Inputs

Approved intake, requirements, current inventory, environment constraints, and organization policies.

## Procedure

1. Identify the system of record and ownership for every entity.
2. Map apps, flows, SharePoint assets, identities, connectors, and external systems.
3. Define schemas and integration contracts.
4. Decide environments, solutions, connection references, variables, and deployment order.
5. Assess security, DLP, licensing, accessibility, records, retention, telemetry, support, and recovery.
6. Map upstream/downstream impact and required regression.
7. Record significant decisions using `templates/architecture-decision.md`.
8. Obtain required approvals before build.

## Output

Architecture diagram, component inventory, decision records, impact map, risks, and regression scope.
