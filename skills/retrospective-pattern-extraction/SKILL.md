# Retrospective and Pattern Extraction

## Procedure

1. Compare actual effort, waiting, rework, defects, and documentation completeness with baseline.
2. Identify where AI accelerated work, increased review, failed, or required human intervention.
3. Separate project-specific lessons from reusable patterns.
4. Promote a pattern only when its inputs, constraints, outputs, and validation are clear.
5. Update the relevant standard, skill, template, and regression checks together.
6. Version the change and record why it was made.
7. Add unresolved improvements to the backlog.

## Output

Metrics summary, retrospective, validated patterns, updated artifacts, and prioritized improvement backlog.
