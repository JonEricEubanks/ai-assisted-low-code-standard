# Power Automate Delivery

## Procedure

1. Confirm trigger, inputs, outputs, owner, identity, connections, and effects.
2. Inspect the current flow, dependencies, backups, and recent failures before editing.
3. Design idempotency, concurrency, retries, timeouts, scopes, logging, alerting, and recovery.
4. Preview material changes before update and preserve a backup.
5. Validate and preflight the definition.
6. Smoke test with synthetic data.
7. Test duplicate, concurrent, authentication, timeout, partial-failure, approval, and recovery paths.
8. Diagnose failures at action/repetition level; never return success for an unhandled failure.
9. Publish only after required approval.
10. Capture run IDs, evidence, release notes, and runbook updates.

## Required outputs

Flow design, dependency inventory, validation result, test runs, failure/recovery evidence, ownership, rollback, and approval.
